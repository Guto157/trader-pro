# TRADER PRO

Plataforma de inteligência esportiva para futebol e basquete.

## Estrutura inicial
- `index.html`: aplicação e componentes da interface.
- `assets/css/style.css`: identidade visual responsiva.
- `assets/js/app.js`: navegação e interações iniciais.

## Publicação
O projeto é estático e pode ser publicado pelo GitHub Pages usando a branch `main` e a pasta raiz.

## Integridade dos dados
A interface não apresenta partidas, estatísticas, odds ou recomendações fictícias. A integração com provedores de dados esportivos e odds será implementada antes de exibir análises reais.

## Próximas etapas
1. Integrar agenda, resultados e estatísticas de futebol e basquete.
2. Implementar motor de análise por mercado, probabilidade, odd justa e valor esperado.
3. Registrar entradas e resultados para métricas de desempenho.
